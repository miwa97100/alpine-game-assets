ALPINE GAME ASSETS — WEBSITE SETUP

1. Open index.html locally in a browser to preview.
2. IMPORTANT: Open index.html in Notepad and replace EVERY occurrence of YOUR-EMAIL@example.com with your real business contact email. Do not publish before doing this.
3. Optional: replace emoji placeholders with real screenshots/renders of the actual models before submitting a portfolio to Unity. The current portfolio explicitly labels them as illustrative icons.
4. Create a public GitHub repository named alpine-game-assets-site (or your preferred name).
5. Upload index.html, logo.webp, banner.webp to the repository ROOT.
6. In GitHub repository Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
7. Wait for the published URL shown in GitHub Pages, usually https://USERNAME.github.io/REPOSITORY/ .
8. Open that link to verify the site, then paste it into Unity Publisher Portal Website field.

Do not use the example email in a published website.
